# Threat Model (`docs/threat-model.md`)

Because this repository is a mathematical proof and research artifact (no network daemon, no user accounts, no personal data), the primary assets at risk are **epistemic integrity**, **formal soundness**, **bibliographic accuracy**, and **build-chain authenticity**.

## Threat Matrix

| Threat ID | Threat | Impact | Likelihood | Concrete Mitigations |
|---|---|---|---|---|
| **T1** | **Proof soundness bypass** (`sorry`, custom `axiom`, `native_decide`, `unsafe`, `implemented_by`, `@[extern]`, or meta-level environment tampering) | False mathematical claim presented as Lean-verified | Medium if unchecked | Nested-comment/string-aware forbidden-token lexer in CI; exhaustive `Lean.collectAxioms` metaprogram in `VerifyAxioms.lean`; six checker runs of `lake comparator --paranoid` (the Lean kernel in paranoid and default mode, `lean4lean`, `nanoda`, `con-leche`, `con-ron`). |
| **T2** | **Definition drift / vacuous formalization** (Lean proves a trivially true or subtly altered version of Conjecture 7.7) | Formal proof passes kernels but does not prove Banić & Elezović's actual conjecture | Medium | Isolated 153-line Mathlib-only `lean/Challenge.lean` (`module` header, 9 targets) with verbatim nested multinomial sum; 20 non-vacuity and adversarial false-constant refutation theorems in `NonVacuity.lean` (6 direct `hAdj 0..5` definition checks + 14 closed-form corollaries, including the proved refutation `adversarial_aTriangle_ne_one_div_32`); mutated-constant elaboration smoke test in CI requiring `unsolved goals`; `docs/statement-fidelity.md` audit table; independent Python exact rational + 80-digit oracle. |
| **T3** | **README / paper claim drift** (human/AI edits manuscript or README without updating verified logs) | Published prose contradicts verified Lean output | Medium | `scripts/check_readme_axioms.py --require-exhaustive` enforces verbatim sync and exact theorem count between `README.md` and `results/lean-axioms-all.log`; `scripts/build_blueprint.py` validates every `\lean{...}` symbol against actual Lean files; `tests/test_repo_integrity.py` verifies exact `paper/main.tex` Table 1 line counts and dynamic portal theorem counts. |
| **T4** | **Citation hallucination or identifier corruption** (e.g., truncated arXiv ID `2610.1336` caught in `E-2026-001`) | Broken or false scholarly attribution | High in AI-assisted writing | `scripts/check_citations.py` static + `--online` DOI/arXiv resolver + bidirectional `\cite`↔`refs.bib` parity; regression test permanently guarding `2610.13366`; Crossref retraction check. |
| **T5** | **Supply-chain / CI tampering** (compromised Mathlib cache, Python package, or release artifact) | Malicious code execution or tampered PDF/tarball | Low–Medium | Pinned `lean/lake-manifest.json` commits, pinned `requirements.txt` (`pytest==9.0.3`, `pygments==2.20.0`, 0 Dependabot alerts, 0 OSV CVEs), `data/MANIFEST.sha256`, dual cryptographic timestamps (`MANIFEST.sha256.tsr` + `MANIFEST.sha256.ots` with 32-byte imprint verification in CI), release `SHA256SUMS`, Sigstore SLSA `actions/attest-build-provenance@v2` verified via `gh attestation verify`, `gitleaks` + SHA-256-verified `osv-scanner v2.7.1`, strict CSP + `sha384` SRI on GitHub Pages, and isolated AST code-mutation auditing (`scripts/run_mutation_audit.py`). |
| **T6** | **Path-handling / shell-injection bugs** (e.g., PowerShell wildcard expansion on bracketed paths like `C:\Projects\[MyRepo]`) | Broken local builds or misdiagnosed missing files | Medium on Windows | All PowerShell scripts (`Audit-Repo.ps1`) use `-LiteralPath` and `[System.IO.Path]::Combine`; Python scripts use `pathlib.Path`, temp-dir OpenSSL staging (`stamp_timestamps.py`), and list-form `subprocess.run(..., shell=False, encoding="utf-8")`. |
